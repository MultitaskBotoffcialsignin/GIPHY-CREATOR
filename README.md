# GIPHY CREATOR

A Discord.js v14 bot that creates animated text GIFs, lets members browse their personal GIF history, and provides a server-specific approved GIF library.

## Commands

- `/creategif` — create a real animated GIF from text. Choose Reaction, Meme, Animated text, or Surprise me. Surprise Me randomizes the text, background, text color, and animation speed.
- `/mygif` — view your recent GIF creation history.
- `/servergif` — view GIFs approved for the current server.
- `/approvegif` — add an attached GIF to the server library (Manage Server).
- `/removegif` — remove a numbered GIF from the server library (Manage Server).
- `/randomgif` — retrieve a random GIF from GIPHY.
- `/trendinggif` — retrieve a trending GIF from GIPHY.

## Setup

1. Use Node.js 20 or newer.
2. Install packages with `npm install`.
3. Copy `.env.example` to `.env` in your hosting environment.
4. Set `DISCORD_TOKEN` to your Discord bot token and `CLIENT_ID` to your Discord application ID.
5. Set `GIPHY_API_KEY` to a GIPHY API key for `/randomgif` and `/trendinggif`.
6. Invite the bot with the `bot` and `applications.commands` scopes. It needs permission to view channels, send messages, attach files, and use application commands.
7. Run `npm run register` once to register slash commands.
8. Run `npm start` to start the bot.

Never commit your real `.env` file or share your bot token. The `.gitignore` excludes it.

## Notes

- GIF creation is generated by the bot; it does not simply return a still image.
- GIPHY API key is only needed for the GIPHY random/trending commands.
- The JSON data files are created in `data/` when the bot runs. Keep persistent storage enabled on your host if you want history and server libraries to survive restarts.
- This starter version stores recent creation metadata for `/mygif`; it does not permanently host generated GIF files.
